# 高尾のパーソナルジム KickFit109（takaogym.netlify.app）

「**高尾 パーソナルジム**」での検索順位を上げるために作り直した、SEO 最適化済みの静的サイトです。
ビルド不要で、`takaogym/` フォルダをそのまま Netlify に公開できます。

## 構成

```
takaogym/
├── index.html            … 1ページ完結（タイトル/見出し/本文/構造化データ/OGP すべて「高尾 パーソナルジム」向けに最適化）
├── 404.html              … エラーページ（noindex）
├── robots.txt            … クロール許可＋サイトマップの場所
├── sitemap.xml           … Search Console に送信するサイトマップ
├── netlify.toml          … 公開設定・/index.html → / の301・セキュリティヘッダー
├── og-image.png          … SNS・LINEでシェアされた時の画像（1200×630）
├── favicon.svg / apple-touch-icon.png
└── README.md
```

## 公開方法（どちらか）

1. **ドラッグ＆ドロップ**：Netlify 管理画面 → `takaogym` サイト → Deploys → この `takaogym` フォルダをドロップ
2. **GitHub 連携**：Site configuration → Build & deploy → Base directory を `takaogym`、Publish directory を `takaogym` に設定

## 🔑 順位を上げるためにサイト外でやること（重要度順）

「高尾 パーソナルジム」のような **地域名＋業種** の検索は、上位に **Google マップ（ローカルパック）** が表示されます。
サイト修正と同じくらい、以下が効きます。

1. **Google ビジネスプロフィールを整える**（最重要）
   - カテゴリに「パーソナルトレーナー」「ジム」を設定
   - ウェブサイト欄に `https://takaogym.netlify.app/` を登録
   - 住所・電話・営業時間をこのサイトと **一字一句同じ表記** にする
   - 写真（外観・室内・トレーニング風景）を定期的に追加、週1回程度「最新情報」を投稿
2. **口コミを集めて返信する**：体験・入会した方に口コミをお願いし、すべてに返信
3. **Google Search Console に登録**
   - プロパティ `https://takaogym.netlify.app/` を追加 → HTMLタグで所有権確認（`<head>` にタグを1行追加）
   - 「サイトマップ」に `sitemap.xml` を送信 →「URL検査」でトップページのインデックス登録をリクエスト
4. **自分の他サイトからリンクを張る**：kickfit109.com・takaokickboxing.com・Instagram・LINE公式のプロフィール等から
   「高尾のパーソナルジム」というリンク文字でこのサイトへリンク
5. **独自ドメインを検討**：`netlify.app` のサブドメインより、`kickfit109.com/personal/` のように
   既存の公式ドメイン配下に置くほうが評価を集めやすくなります
6. **似た内容のサイトを乱立させない**：同じジムの紹介サイトが複数（neocities / inkrich / netlify 等）あると、
   評価が分散したり、Google に「誘導ページ」とみなされるリスクがあります。
   サイトごとに役割（パーソナル／キック／ヨガ）を分け、住所表記を統一し、互いにリンクしてください

## 更新時のメモ

- 料金・営業時間を変えたら、本文と構造化データ（`ExerciseGym`・`FAQPage`）の両方を更新
- 更新したら `sitemap.xml` の `<lastmod>` と、構造化データの `dateModified` を更新日に変更
- ローカル確認：`cd takaogym && python3 -m http.server 8000` → http://localhost:8000
