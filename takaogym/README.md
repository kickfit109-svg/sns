「**高尾 パーソナルジム**」で上位表示を狙うための、SEO 強化版トップページです。
現行サイトの文章・料金・構成はそのままに、検索エンジン向けの部分を強化しています。
ビルド不要で、`takaogym/` フォルダをそのまま Netlify に公開できます。

### ⚠️ Netlify のドラッグ＆ドロップ公開について

ドラッグ＆ドロップで公開すると **サイト全体がフォルダの中身に置き換わります**。
現行の画像やトレーナー紹介ページが消えないよう、**それらのファイルもこのフォルダに入れてから** 公開してください。
（Netlify 管理画面 → Deploys → 現在のデプロイ → 「Download」で現行ファイル一式を取得できます）

### 現行サイトを残したまま、最小限だけ直す場合

現行の `index.html` の `<head>` 内で、次の3点だけ差し替えても効果があります。

1. `<title>` をこの版と同じものに
2. `<meta name="description">` をこの版と同じものに
3. この版の `<script type="application/ld+json">…</script>` をまるごと `<head>` に追加

あわせて h1 に「高尾のパーソナルジム」を入れ、`robots.txt` と `sitemap.xml` をサイトのルートに置いてください。

## 🔑 順位を上げるためにサイト外でやること（重要度順）

「高尾 パーソナルジム」のような **地域名＋業種** の検索は、上位に **Google マップ（ローカルパック）** が出ます。

1. **Google Search Console に登録**（まだインデックスされていないため最優先）
   - プロパティ `https://takaogym.netlify.app/` を追加 → HTMLタグで所有権確認
   - 「サイトマップ」に `sitemap.xml` を送信 →「URL検査」でトップページの **インデックス登録をリクエスト**
2. **Google ビジネスプロフィールを整える**
   - ウェブサイト欄に `https://takaogym.netlify.app/` を登録
   - カテゴリ「パーソナルトレーナー」、ビジネス名・説明文に「高尾」「パーソナルジム」
   - 写真を定期的に追加、週1回程度「最新情報」を投稿
3. **住所をサイトに載せる**：ビジネスプロフィールと **一字一句同じ表記** で本文・構造化データに記載すると、地域検索で強くなります
4. **口コミを集めて返信する**：体験した方に口コミをお願いし、すべてに返信
5. **自分の他サイト・SNSからリンク**：kickfit109.com・Instagram・LINE公式のプロフィール等から「高尾のパーソナルジム」の文字でリンク
6. **独自ドメインを検討**：`netlify.app` のサブドメインより、独自ドメインのほうが評価を積み上げやすくなります
