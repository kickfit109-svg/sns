# 川上かずき 公式サイト（kawakami/）

都民ファーストの会 市政改革委員（八王子担当）・川上かずきの公式サイトです。
ビルド不要の静的サイトで、`kawakami/` フォルダをそのまま Netlify などに公開できます。

> **公開前に、必ず [COMPLIANCE.md（公職選挙法チェック）](COMPLIANCE.md) を読んでください。**
> 特に「2. 高校の講師としての制約」と「5. 経歴の書き方」は、公開前の確認が必須です。

## 戦略メモをどう反映したか

| 戦略メモ | サイトでの反映 |
|---|---|
| キャッチは「最年少への挑戦！」にしない | トップコピーは「八王子と生きる。」（ご本人の決定）。「最年少」「25歳」はどこにも書いていない |
| 子どもを選挙の小道具にしない。家族の露出は節度を | 子どもが写った写真はゼロ。「二人の子どもの父」は事実として一言だけ |
| 「スター候補」にしない。見た目・経歴＝若い／中身＝意外に堅実 | 都民ファーストのグリーンで爽やかに見せつつ、見出しは明朝体で落ち着きを残す。動きはフェード・ワイプ中心で、派手な演出はしない。ガッツポーズ写真は不使用。格闘技はプロフィールの1行のみ |
| 「政治家になりたい25歳」ではなく「すでに地元で活動している25歳」 | 「現場から」セクションで教育・子育て・地域スポーツ・起業の4つの現場を紹介し、「この街で続けてきたことの延長線上に、市政があります」で締める |
| 全部、自分の人生から語れる政策に | チラシの6政策それぞれに「現場から」（なぜ自分が言うのか）を添えた |
| 政策も欲張らない（子育て・教育・スポーツ部活動・若者） | チラシの6政策のみ。財政・都市計画などには広げていない |
| 若者票を集めようとしすぎない。本人→親→祖父母世代を縦に | 政策6（シニア）と、親世代向けの「市議会ガイド」で幅広い世代に届く構成 |

### チラシから変えた・補った点

- **コピーの統一**：トップコピーは「八王子と生きる。」です。チラシは「この街で育ち、この街で働き、この街で子どもを育てる。」のままなので、次に印刷するときはチラシ・名刺・SNSのプロフィールも「八王子と生きる。」に揃えるのがおすすめです。
- **部活動**：国の呼び方が2025年に「地域移行」から「地域展開」に変わり、2026年度から「改革実行期間」に入っています。サイトでは「部活動の地域展開（地域移行）」と両方を書き、検索にも対応させました。
- **てくポ**：「てくポ」は60歳以上向けの市の健康ポイントで、すでにボランティアなど社会参加にもポイントが付きます。「拡大」だけだと「もうやっている」と指摘されうるため、「対象を、スポーツや地域活動へ **さらに** 広げる」としました。印刷物も合わせるのがおすすめです。
- **写真**：チラシの写真はAI生成と思われるため、サイトでは使っていません（COMPLIANCE.md の6）。

## デザインとアニメーション

### カラー
`assets/style.css` の先頭で色を一括管理しています。

| 変数 | 色 | 用途 |
|---|---|---|
| `--brand` | `#00a041` | 都民ファーストグリーン（大見出しの強調、線、丸、背景の面） |
| `--brand-strong` | `#007a35` | ボタン・リンク・小さな緑文字（白地で読みやすい濃さ。コントラスト比 5.5:1） |
| `--brand-deep` / `--brand-ink` | `#0b5c33` / `#053822` | 濃い緑の帯（ビジョン、フッター） |
| `--brand-lime` | `#8ccf3f` | グラデーションの明るい側 |

※ 制作環境から党の公式サイトに接続できず、**党の公式カラーコードは未確認** です。党から指定の色をもらったら、`--brand` の1行を差し替えれば全体に反映されます（文字やボタンに使う `--brand-strong` は、白地で読める濃さを保ってください）。

### 動き
- **ヒーロー**：見出しが1行ずつせり上がり、写真が下からワイプ表示、緑のフレームと名札・丸いバッジ（ゆっくり回転）が順に登場
- **背景**：緑のぼかし円がゆっくり漂い、「KAWAKAMI KAZUKI / HACHIOJI」の白抜き文字が流れる
- **帯**：「子どもが育つ。スポーツを楽しむ。…」が横に流れる（マウスを乗せると一時停止）
- **スクロール**：英字見出し（On the Ground / Message / Policy …）が左からワイプ、カードが順番にフェードイン、メッセージの写真は視差で動く、「延長線上に、市政があります。」にマーカーが引かれる
- **ホバー**：カードが浮き上がり緑のラインが伸びる、ボタンに光が走る
- **ヘッダー**：スクロールで白背景に切り替わり、下端に緑の進捗バー。右下に「トップへ戻る」ボタン
- **市議会ガイド**：数字（40人・4年…）がカウントアップ

**配慮**：
- スマホやパソコンで「視差効果を減らす」設定にしている方には、動きをすべて止めて最初から全文を表示します。
- JavaScript が動かない環境でも全文が読めます。読み込みに失敗しても、2.5秒後には必ず表示されます。

## 公開手順（Netlify）

1. Netlify で新しいサイトを作成し、`kawakami/` フォルダをドラッグ＆ドロップ
   （GitHub 連携なら Base directory を `kawakami` に）
2. サイト名を `kawakami-kazuki` にすると、`https://kawakami-kazuki.netlify.app` で公開されます
3. **Forms**：管理画面 → Forms → 「Enable form detection」をオン → 再デプロイ
   → Forms → Form notifications → Email notification で、受け取りたいメールアドレスを設定
4. 公開後、スマホで「ご意見を送る」を実際に送信し、完了ページとメール通知を確認

※ Netlify 以外（GitHub Pages など）で公開する場合、フォームはそのままでは動きません。Googleフォームなどに置き換えてください。

ローカル確認：`cd kawakami && python3 -m http.server 8000` → http://localhost:8000

## SEO：狙う言葉と、狙う時期

ご希望の「八王子市議会議員」「八王子市議会議員選挙」「八王子市議選」について、正直な見立てです。

| 言葉 | いつから | このサイトの対応 |
|---|---|---|
| 川上かずき／かわかみかずき | **今すぐ（最優先）** | title・h1・構造化データ（Person）に設定。チラシや街頭で名前を知った人が必ず検索するため、ここで確実に1位を取ることが一番大事です |
| 都民ファーストの会 八王子 | 今すぐ | title・肩書きに設定 |
| 八王子 学童 待機児童／八王子 部活動 地域展開／八王子 放課後 など | 今すぐ | 6政策の本文に自然に配置。政策ごとの記事を増やすほど伸びます |
| **八王子市議会／八王子市議会議員** | 今すぐ | 「はじめての八王子市議会ガイド」（/gikai/）で受け止め。議員の仕事・委員会・傍聴・請願を解説 |
| **八王子市議会議員選挙／八王子市議選** | **告示日から本格的に** | 告示前は、ガイドのFAQで任期満了日（2027年4月30日）と選管ページを中立的に案内するのみ。告示日に title・見出しを切り替え（下記） |

**現実的な話**：「八王子市議選」で検索上位に来るのは、選挙管理委員会・選挙ドットコム・報道です。候補者サイト単独でそこを抜くのは難しく、告示前にこの言葉を前面に出すと事前運動のリスクだけが残ります。勝ち筋は次の3つです。

1. **指名検索（名前検索）で確実に1位**：選挙前に名前を知った人は、必ず名前で検索します
2. **選挙ドットコム（go2senkyo.com）の政治家ページを登録・充実** させ、そこから本サイトへリンク：選挙名の検索は、こうしたサイト経由で流れてきます
3. **告示日に選挙モードへ切り替え**：告示前に積み上げたサイトの評価が、そのまま選挙期間に効きます

### サイトの外でやること（重要度順）

1. **Google Search Console に登録** → `sitemap.xml` を送信 → トップと /gikai/ の「インデックス登録をリクエスト」
2. **独自ドメインを早めに取得**（例：kawakami-kazuki.jp）。ドメインは使った期間が評価に効くため、選挙直前より今がおすすめです
3. **Instagram・X・Threads・note のプロフィール** に本サイトのURLを掲載
4. **都民ファーストの会の八王子関連ページ** からのリンクを党に相談
5. **活動レポートを月2本以上**：市議会の傍聴レポート、政策の深掘り、地域の話。（このリポジトリの `snsgrow` で作ったSNS投稿と連動させると効率的です）
6. **リスティング広告（Google広告など）は使わない**（COMPLIANCE.md の9）

### 追加すると強くなるコンテンツ

- **地域の方の声**（戦略メモの「地域の信用ある50〜70代」）：少年野球・教育・商店会・町会・スポーツ関係の方から、**人柄について** の短いコメント。必ずご本人の同意を取り、文面に「投票」「応援」「当選」を入れないこと。架空の声は絶対に載せないこと。追加するなら「現場から」セクションの下に、次の形で入れられます：
  ```html
  <figure class="genba-card">
    <blockquote><p>「（ご本人に書いていただいた言葉を、そのまま）」</p></blockquote>
    <figcaption>（お名前）さん（（団体・肩書き）・（年代））</figcaption>
  </figure>
  ```
- **学歴**（例：八王子市立〇〇小学校・〇〇中学校）：地元の同窓のつながりに強く効きます。プロフィールの表に1行追加してください
- **活動レポート**：傍聴した日の一般質問の要約など。「八王子市議会」系の検索を継続的に取れます

## 告示日の切り替え手順（選挙モード）

告示日（立候補届出の日）の **届出が受理されてから** 行ってください。

1. `index.html` の `<title>` を、たとえば次のように変更
   `川上かずき｜八王子市議会議員選挙 候補者（都民ファーストの会）`
   （公認・推薦の別は正確に）
2. `<meta name="description">` に「八王子市議会議員選挙」を追加
3. ヒーローの肩書き（`hero-role`）を「八王子市議会議員選挙 候補者　都民ファーストの会」に変更
4. フッターの連絡先に、フォームのURLを **文字でも** 記載（例：`https://kawakami-kazuki.netlify.app/#voice`）
5. ヒーローの下かフッターに注意書きを追加：
   「18歳未満の方は、選挙運動（SNSでのシェア・リポストを含む）を行うことはできません。」
6. **投票日の前日のうちに最後の更新を終える**。GitHub と自動連携している場合は、Netlify の「Stop auto publishing」で **投票日当日に更新されない** ようにしておく
7. 選挙が終わったら、当選・落選のごあいさつはサイト・SNS上で行えます（印刷したあいさつ状・戸別訪問・新聞広告などは不可）

## 更新時のメモ

- 内容を更新したら、`sitemap.xml` の `<lastmod>` と、`index.html` の構造化データ `dateModified` を更新日に
- 政策を変えたら、トップの政策カードと、チラシの表現を揃える
- 写真を差し替えるときは、webp と jpg の両方を同じ名前で置き換え（`assets/img/`）
